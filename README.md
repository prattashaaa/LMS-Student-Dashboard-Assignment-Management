# LMS - Student Dashboard and Assignment Management

## Project Overview

This project is a Web-Based Learning Management System (LMS) developed to support academic management and online learning.

## My Chosen Work

My chosen area of contribution is **Student Dashboard and Assignment Management**.

### Student Dashboard
The student dashboard provides students with access to important academic features and information through a centralized interface.

### Assignment Management
The assignment module allows students to view available assignments, access assignment details, and submit their completed assignments through the system.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Files Included

- `dashboard_student.php` - Student dashboard
- `assignment_student.php` - Student assignment page
- `submit_assignment.php` - Assignment submission
- `assignment_link_student.php` - Assignment links
- `assignment_sidebar.php` - Assignment navigation
- `submit_assignment_sidebar.php` - Submission navigation
- `student_sidebar.php` - Student navigation
- `header_dashboard.php` - Dashboard header
